# TubaCity

Site de agenda cultural feito em React, Vite e Tailwind CSS para um trabalho da FIEC.

## Como rodar

```bash
npm install
npm run dev
```

## Requisitos

- Eventos com data, horário, local, descrição, imagens, categorias e links.
- 1.1.1 — Conteúdo não textual (A): Imagens com texto alternativo.
- 1.3.1 — Informações e relações (A): Uso de HTML semântico.
- 2.1.1 — Teclado (A): Navegação por teclado/tab.
- 2.4.2 — Página titulada (A): Título da página.
- 2.4.6 — Títulos e rótulos (AA): Títulos e links descritivos.
- 2.4.7 — Foco visível (AA): Foco visível.
- 3.1.1 — Idioma da página (A): Idioma definido como português.
- 3.3.2 — Rótulos ou instruções (A): Textos identificam os controles.
- 1.2.2 — Legendas (A),: Não utilizado, pois não há vídeos.
- 1.4.13 — Conteúdo em hover ou foco (AA): Não há conteúdo extra exibido apenas ao passar o mouse.
- 2.4.11 — Foco não oculto (AA): Foco sem elementos fixos escondendo-o.
- 2.5.8 — Tamanho mínimo do alvo (AA): Botões e links com tamanho adequado.

O site também possui modo escuro. Os eventos são fictícios.
